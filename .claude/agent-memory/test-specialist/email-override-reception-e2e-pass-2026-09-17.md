## Process notes

- No `git stash`/`checkout`/`reset` used anywhere, per [[never-touch-git-state-uninstructed]] — the tree had ~17 modified files from other concurrent work throughout this pass, none of it touched.
- `playwright-cli` global wrapper is still broken exactly as documented in [[known-issue-playwright-cli-wrapper-broken]]; resolved `@playwright/cli`'s real bin the same way.
- TinyMCE body fields for the override editor are reachable via `window.tinymce.get('law-eo-body-main'|'law-eo-body-free').setContent(html)` then `.save()` to sync the underlying `<textarea id="law-eo-body-main"|"law-eo-body-free">` — much faster and more reliable than trying to click/type into the iframe directly.
- Confirming the free "Register" button on a reception page doesn't always cause a visible URL navigation on the same command that clicks it (checked via `/account/bookings/` afterwards instead) — don't assume a same-URL result after clicking "Confirm my free place" means the booking failed; verify via My bookings or Mailpit before concluding anything.
